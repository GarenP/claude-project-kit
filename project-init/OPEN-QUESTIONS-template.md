# OPEN QUESTIONS — {Project Name}
*The artifact that backs "carry questions forward" — memory is not trusted. The moment a question is asked and not immediately answered, it gets a row here. The moment it's answered, mark it `ANSWERED` with where/when. Run `python check_open_questions.py` at session end — it FAILS if any row is still `OPEN`.*

**Statuses:** `OPEN` = asked, not answered (checker FAILS) · `ANSWERED` = resolved (note where) · `DEFERRED` = parked with an owner + venue (checker passes, but lists it so it's never forgotten).

*(Why this exists: questions get dropped in long free-form back-and-forth when "carry it forward" lives only in prose — a 2nd or 3rd question buried in a multi-part message vanishes. This file makes carrying-forward checkable, not a matter of memory.)*
